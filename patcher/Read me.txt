WA2 Dream Communication for Windows - Patcher
==============================================

This patcher turns the Android XAPK of WHITE ALBUM2 ～ドリームコミュニケーション～ (version 1.0.7)
into the complete Windows game.


What you need
-------------
- Your WA2DC 1.0.7 XAPK. This is the file that contains jp.aquaplus.DreamCommunication.apk and the
  OBB.
- About 250 MB of free space for the game, plus about 220 MB of temporary space while it installs.


How to install
--------------
1. Keep "WA2DC Patcher.exe" and "WA2DC_Patch.dat" together in the same folder.
2. Run "WA2DC Patcher.exe", choose your XAPK, then choose the folder for the game.
   If that folder isn't empty, a WA2DC subfolder is created inside it.
   Options:
   - Use the bundled strip art: the artwork shown in the side strips (on by default).
   - Create the 1920x1080 launcher.
3. Press Install. It takes a few minutes. The window shows the current file and the time left.
4. Press Play now, or create a desktop shortcut.


What the patcher does with your data
------------------------------------
Your XAPK is only read, never changed. The game is rebuilt from it in four kinds of steps:

- Unchanged game files are copied out of the XAPK (from the APK and the OBB inside it). Each one is
  checked against its recorded CRC32.
- Game files the port changes are rebuilt from your own copy with a small Windows delta (msdelta).
  These are the retargeted data files, the texture fixes and the two recompiled game assemblies.
- The 255 AssetBundles are unpacked, patched with a delta of a few hundred bytes, and re-compressed
  with the exact LZMA settings of the Windows build.
- The Unity 3.5.6 Windows player, version.dll (the Saves tab), the launchers and the strip art
  come from WA2DC_Patch.dat.

Every result is checked against its target CRC32. The install is assembled in a temporary staging
folder and moved into place only when everything has passed. The finished folder is byte-for-byte
the same as the reference Windows build.


Playing
-------
- WA2DC.bat starts the game in a 1024x768 window.
- WA2DC-1080p.bat switches to 1920x1080 fullscreen.
- Unity's configuration dialog appears first. The Graphics tab sets the resolution and window mode.
  The Saves tab lists your saves with the WP left in each and when it was last played; pick one, or
  pick New save to start without progress. Then click Play!.
- Alt+Enter toggles fullscreen.
- Saves are in the Documents folder inside the game folder. save.bin holds your progress and
  share.bin holds the store and DLC state. Save 1 is Documents itself; each new save gets its own
  folder in Documents\Saves. The owned DLC is unlocked in every save, new ones included.
- The store's real-money purchases are offline. The owned DLC is already unlocked, and gallery pages
  unlock with WP as in the original.
- The window can't be resized while the game runs. Use Alt+Enter or the 1080p launcher instead.


If something goes wrong
-----------------------
- A damaged or different XAPK stops the install with the name of the entry that failed. Nothing is
  written in that case.
- Cancelling removes the temporary staging folder and leaves the destination as it was.
- WA2DC_Patch.dat must be in the same folder as WA2DC Patcher.exe.


Silent install (for testing)
----------------------------
    "WA2DC Patcher.exe" /auto <xapk> <destination>

This installs without the wizard. It writes patcher-auto.txt next to the exe (OK, or the error) and
returns exit code 0 on success and 1 on failure.
